# Contributing to this profile

This repository contains Mike Hamanaka's [GitHub profile README](README.md).
Contributions can improve its wording, public links, navigation, and readability.

## Propose a profile correction

In an issue or pull request here, identify the section or link, describe the
problem, and suggest a focused correction. Include a public source when changing
a project description, such as that project's README, documentation, or release
notes. Distinguish a project's intended role from its documented capabilities.

For installation problems, feature requests, or bugs in a linked project, use
that project's contribution guidance and issue tracker. The
[project directory](README.md#the-ecosystem) links to the relevant repositories.

## Check the change

- Preview the README as rendered Markdown. Check heading order, table layout,
  descriptive link text, and readability at a narrow window width.
- Open new or changed external links while signed out. Confirm that they lead
  to the intended public repository or documentation and do not require private
  access. Prefer HTTPS links without credentials or access tokens.
- Check relative links against the exact file names and heading anchors in this
  repository. Keep the existing project links unless the correction concerns
  their destinations.
- Review the diff and run `git diff --check` for whitespace errors. Describe the
  checks you actually completed; record unavailable links or uncertain claims
  instead of reporting them as verified.

Include what changed, why it helps, and the relevant verification in the pull
request description. Keep unrelated changes separate so the correction is easy
to review.

## Use public, non-sensitive evidence

Use synthetic examples where examples are useful. Keep secrets, access tokens,
private logs, private repository contents, and internal operational details out
of issues, pull requests, screenshots, and commits. Check screenshots and pasted
output for identifying data before including them. Public source links are
usually sufficient to explain a profile correction.
